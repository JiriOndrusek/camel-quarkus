# Test Coverage Plan: integration-tests/pqc

## Documentation summary

The PQC (Post-Quantum Cryptography) component provides quantum-resistant cryptographic capabilities for Apache Camel using BouncyCastle's PQC provider. The component supports:

- **Signature operations** (sign/verify) using NIST-standardized algorithms:
  - ML-DSA (Dilithium) - with parameter specs: dilithium2, dilithium3, dilithium5
  - Falcon - with parameter specs: falcon_512, falcon_1024
  - SPHINCS+ - with multiple SHA2 and SHAKE variants across security levels (128f/s, 192f/s, 256f/s)

- **Key Encapsulation Mechanism (KEM)** operations (encapsulation/extraction) using:
  - Kyber - with parameter specs: kyber512, kyber768, kyber1024
  - Symmetric key algorithms: AES (128/256-bit) and CHACHA7539 (128/256-bit)

The documentation covers URI format and syntax, operation types, configuration options (component and endpoint level), message headers (CamelPQCSignature, CamelPQCVerification, CamelPQCSecretKey), message body behavior, KeyPair generation and management, BouncyCastle provider integration, error handling, native compilation support, and performance considerations.
