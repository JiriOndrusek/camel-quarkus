## Component summary

The PQC component provides post-quantum cryptographic capabilities for Apache Camel, supporting signature operations (sign/verify) with ML-DSA (Dilithium), Falcon, and SPHINCS+, and KEM operations (encapsulation/extraction) with Kyber. It integrates BouncyCastle's PQC provider for quantum-resistant cryptography.

## Existing test files

- `integration-tests/pqc/src/test/java/org/apache/camel/quarkus/component/pqc/it/PqcTest.java` - JVM mode tests (6 test methods)
- `integration-tests/pqc/src/test/java/org/apache/camel/quarkus/component/pqc/it/PqcIT.java` - Native mode tests (extends PqcTest)

## Gaps in test coverage

### Critical Security Gaps (P0)
1. **Invalid signature verification** - No test verifies that corrupted signatures fail verification
2. **Algorithm mismatch detection** - No test ensures cross-algorithm operations fail properly (e.g., sign with Dilithium, verify with Falcon)
3. **Wrong key detection** - No test verifies KEM extraction fails with wrong private key
4. **Corrupted data handling** - No tests for corrupted encapsulation data or signatures
5. **Null/missing parameter validation** - No tests for missing keyPair, operation, or algorithm parameters

6. **Algorithm parameter spec variations** - Only tests 4 of 16+ available parameter specs
