# **PQC Component - Test Coverage Brief**

## **Component Summary**

The PQC (Post-Quantum Cryptography) component provides post-quantum cryptographic capabilities for Apache Camel, enabling quantum-resistant digital signatures and key encapsulation mechanisms (KEM). The component leverages BouncyCastle's PQC provider to implement NIST-standardized algorithms including **ML-DSA (Dilithium)**, **Falcon**, **SPHINCS+**, and **Kyber**. It supports both signature operations (sign/verify) and KEM operations (encapsulation/extraction) for secure key exchange resistant to quantum computing attacks.
